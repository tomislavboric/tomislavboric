### Hi, I'm Tomislav 👋

Senior frontend engineer in Zagreb, Croatia, working remotely. I build web products from the first sketch to production.

- I've been doing frontend work for seventeen years. Five of those were at **Sched**, an event-management SaaS, on the product and growth teams.
- For the last year I've been building **Camppy**, my own campsite-operations platform, with Vue 3 and Supabase. It's a PWA that field teams use from their phones, with an offline queue, row-level security and a twelve-language interface.
- Through my studio **inWeb** I've done more than twenty custom WordPress builds, and lately headless Next.js work.

I care about interfaces people understand at a glance, and about code the next person can read.

#### Open source, extracted from production

Small, tested pieces pulled out of Camppy, where they run in production:

| Repo | What it solves |
| --- | --- |
| [pinia-idb-persist](https://github.com/tomislavboric/pinia-idb-persist) | Persists large Pinia stores to IndexedDB, and only when needed. This avoids localStorage's quota and the cost of serializing the store on every click. |
| [pwa-survival-kit](https://github.com/tomislavboric/pwa-survival-kit) | Recovers from deploy skew (404s on stale chunks), fixes the iOS home-screen viewport and compresses photos on the device before upload. |
| [brand-contrast](https://github.com/tomislavboric/brand-contrast) | Turns any brand colour into WCAG-readable text and accent tokens. |
| [vue-mobile-patterns](https://github.com/tomislavboric/vue-mobile-patterns) | A swipe-to-dismiss bottom sheet, drag-to-reorder, a toast queue that dedupes, and coalesced autosave. |
